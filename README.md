# Portfolio

My personal portfolio built with plain HTML, CSS, and JavaScript.

> **Work in Progress**
>
> The content is mostly placeholder for now. I'm currently focused on building the application itself, so the projects, descriptions, and other information will be updated over time.

## Why does it look like this?

I spend most of my time on Linux using KDE Plasma, Neovim, Zsh, and the terminal. I really like the look of translucent windows and blur effects, so instead of making another typical portfolio website, I wanted to build something that felt more like my own desktop.

It's not meant to imitate a terminal perfectly. It's just inspired by the tools and environment I use every day.

## Features

- Built with HTML, CSS, and JavaScript
- No frameworks or build tools
- Responsive layout
- Terminal-inspired interface
- Blur and glass effects inspired by KDE Plasma
- Floating project launcher
- Modular JavaScript code

## Project Structure

```text
.
├── assets/
├── css/
├── js/
├── pages/
├── projects/
└── index.html
```

I tried to keep the project modular by splitting different parts of the application into separate files instead of putting everything into one script. That makes it easier to add new features or change existing ones without affecting the rest of the project.

## Running locally

I usually run it using the Live Server plugin from Neovim:

```bash
nvim --headless +"LiveServerStart"
```

Since it's just a static website, any local web server will work.
