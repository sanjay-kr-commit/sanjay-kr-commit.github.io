Workspace

The environment where ideas become repositories.

Why My Workspace Matters

My development environment has evolved over time alongside my projects. I treat it as another engineering project: something to refine, automate, and understand. Every tool in my workflow exists because it solves a recurring problem or removes friction from everyday development.

Operating System

My primary operating system is Linux with KDE Plasma as the desktop environment. Instead of replacing the desktop with a standalone tiling window manager, I extend Plasma using Krohnkite, virtual desktops, and custom KWin effects to create a workflow that balances flexibility with productivity.

This interest in desktop customization naturally led me to explore Plasma widgets, desktop scripting, and contributing to open source projects related to the Linux desktop ecosystem.

Development Tools

  • Neovim for editing and navigation.
  • tmux for persistent terminal sessions.
  • Konsole as my primary terminal emulator.
  • Git for version control and experimentation.
  • LazyGit for an efficient terminal Git workflow.

My Neovim configuration is modular and continues to evolve with plugins, language tooling, debugging support, and custom automation tailored to my daily workflow.

Supporting Applications

  • Zen Browser for research and documentation.
  • Obsidian for technical notes and learning.
  • Harmonoid for music while coding.
  • OBS Studio for recording demonstrations and experiments.

These applications support the engineering process without distracting from it. Documentation, research, and communication are just as important as writing code.

Automation

Whenever I notice myself repeating the same sequence of commands, I look for an opportunity to automate it. Small shell scripts, Git helpers, editor commands, and desktop integrations accumulate over time, gradually improving the overall development experience.

Many of these automations eventually become standalone repositories or are integrated into my dotfiles.

Workspace Principles

Minimal Keyboard Driven Repeatable Automated Documented Customizable

The goal is not to create a visually impressive desktop but to build an environment that stays out of the way and lets me focus on understanding and creating software.
